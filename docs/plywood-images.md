# Plywood images

The sheets in `public/images/plywood` sit behind holds on the pages and on the
board in the 3D viewer. Each was resized and saved as WebP; nothing else was
changed, apart from the crops noted below.

## Photographs

From Unsplash, under the [Unsplash License](https://unsplash.com/license)
(free to use, no attribution required). None is an Unsplash+ image.

| File             | What it is                               | Source                                                                                |
| ---------------- | ---------------------------------------- | ------------------------------------------------------------------------------------- |
| `sheet.webp`     | A cheap sheet with stains and patches    | https://unsplash.com/photos/a-wall-that-has-some-brown-paint-on-it-sVRj2P8m-9U        |
| `birch.webp`     | A cleaner birch face                     | https://unsplash.com/photos/light-brown-wood-grain-texture-background-2ZX2HqdxcC8     |

## Generated images

No freely licensed photo of the back of a home board turned up, so these two
were generated with OpenAI image generation through the Codex CLI. They are
not photographs of a real board.

| File               | What it is                                                   |
| ------------------ | ------------------------------------------------------------ |
| `board-front.webp` | The climbing side of a pine plywood board: a grid of holes   |
| `board-back.webp`  | The back of the same board: four-prong T-nuts hammered in    |
| `panel-front.webp` | A square crop of the front, centred on one hole (3D viewer)  |
| `panel-back.webp`  | The matching crop of the back, mirrored, as seen from behind |
